# Emails from FoC

## What emails does FoC send?

FoC sends two kinds of email, both for account security:

- a **one-time code** when you register, to prove the address is yours
- a **password reset link** when you ask for one on the sign-in page

Both come from Friend on Campus and last 10 minutes. FoC does not currently email you about errands or credits.

## Why did my FoC email not arrive?

Email can take a moment to arrive. If it has not arrived after a minute or two:

1. Check your junk or spam folder.
2. Check that you typed your NUS address correctly.
3. Ask for a new code or link, and use the newest email.

For a password reset, FoC may not confirm whether an address has an account, so check that you used the address you registered with.

## I received an FoC email I did not ask for. What should I do?

If you did not ask for a code or reset link, someone may have typed your address by mistake. Do not share the code or link with anyone, and nothing will change: the code and link stop working after 10 minutes, and your password stays the same unless the link is used. FoC never asks you for your password or code by chat or email. If it keeps happening, contact an admin.

## Why did I get the same FoC email twice?

An email can occasionally arrive twice. It is harmless. If you asked for a new code yourself, use the newest one, because a new code replaces the old one.
